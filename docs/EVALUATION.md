更新：2026-09-15。所有“胜率”均指指定对手池下的**夺冠份额，并列第一平分**。各人数、牌池和对手池独立报告，不能混成总榜。

## 1. 当前部署模型

| 场景 | 最终模型 | 夺冠份额 | 该模型对局数 / 独立发牌组 |
|---|---|---:|---:|
| 三人 / 104 张 | distill2048-specialist2048 | 58.36% | 6,144 / 2,048 |
| 四人 / 104 张 | distill2048-specialist2048 | 47.79% | 8,192 / 2,048 |
| 二人 / 104 张 | V6 | 55.66% | 512 / 256 |

对手池包含三个神经策略、DirV 与 Alpha 本地复现、MCS 适配、冠军搜索和随机策略。模型与对照在相同牌局和全部座位轮换下配对，按独立发牌组重采样；当前模型的提升通过对应的比较校正。人类玩家、全部同款冠军对手或其他策略组合不保证复现此胜率。

原始结果：[三四人](../artifacts/progressive-upgrades/certificate-004/results.json)、[二人 V6](../artifacts/small-player-exploration/classic2-results.json)；[正式结果独立审计](../artifacts/progressive-upgrades/independent-completion-audit.json)。

四人主比较为 512 局 / 128 组发牌；规则敏感性为复用其中 64 组的 256 局；两种二人场景各 256 局 / 128 组。95% 区间采用 20,000 次完整发牌组 bootstrap，补充场景未作多重比较校正。

同价强制选行时，本项目再选最短、最前的行，take6 再选行尾最大的行。二人 take6 权重的原生牌池是 24 张，104 张结果属于迁移；24 张测试中的本地对手是兼容策略，不能把它写成 V6。

take6 使用[作者发布的原始权重](https://github.com/GiovanniGatti/take6/tree/d498ab89fb74f9175e5ce1b0897eba1d5b3ffb7c/trained-anns)，按默认概率抽样出牌，未重训。本机采用经过数值验证的 FP32 PyTorch 推理移植，并非原始 TensorFlow 运行时；1,920 个局面通过编码与概率核验，全部 12,800 次实际出牌与独立 NumPy 重建一致。

证据：[结果](../artifacts/take6-evaluation/results.json)、[冻结协议](../artifacts/take6-evaluation/protocol.json)、[实际出牌审计](../artifacts/take6-evaluation/decision-audit.json)、[原始权重与源码摘要](../external/take6/provenance.json)。

## 3. 对外比较的结论边界

- **四人 / 104 张**：本地冠军在上述已测固定对手池中表现最好；尚未覆盖所有公开预训练模型。
- **二人并非全面领先**：24 张场景 take6 胜过网页兼容策略；V6 在另一批二人 / 104 张测试中，对 MCS、DirV 的点估计分别为 40.00%（60 局）、45.95%（74 局），样本有限。[分项结果](../artifacts/small-player-exploration/secondary-analysis.json)
- **原始模型与复现不同**：take6 使用作者权重；MCS 为代码适配，Alpha、DirV 为本地重新实现和训练，不能当作作者原版实测。闭源原版系统未测试。
- **计算预算不同**：本地冠军每候选 2,048 世界，MCS 每步约 100 条总续局，DirV / Alpha 模拟上限 200 / 50，take6 一次网络前馈；没有证明等算力优势。

结论限于当前模型、规则、对手池和预算，不宣称“超过所有开源或闭源模型”。运行和权重位置见 [技术说明](TECHNICAL_REPORT.md)。
