# 实验与模型产物导航

本目录保留原始路径，以维持历史 manifest 和 SHA-256 审计。当前推荐入口见 [模型索引](../models/README.md)，完整依赖见 [registry.json](../models/registry.json)。

| 目录 | 角色 |
|---|---|
| `progressive-upgrades/` | 当前三四人冠军、开发选拔、四次正式验收、接受状态和独立审计 |
| `small-player-exploration/` | 二人 V6、原始八策略池及探索记录 |
| `small-player-iterations/` | 早期迭代模型；其中 V4 仍是冠军依赖 |
| `models/` | 历史权重、浏览器导出和模型配置；部分整组被旧清单固定 |
| `web-integration/` | 本次网页接口的归档决策对照、测试记录和服务日志，不是新增胜率证据 |

其他实验目录属于历史研究资料。训练数据、未通过候选和中间检查点的复核位置可查 [inventory.json](../models/inventory.json)。标记为待复核并不意味着可直接删除；正式验收失败记录也属于统计证据。
